# Pelin idea
# Asut kylässä, ja kylän maatilasta on vesi kulumassa loppuun. Sinun tulee keksiä veden lähde maantilalle. Loppuja on kolme, riippuen minkä vedenlähteen pelaaja hankkii. Pelaajalla on ajettava pakettiauto, jolla hän pääsee liikkumaan kylän, metsän, lähikaupan ja kaupungin välillä. Pakettiauto tarvitsee dieseliä, ja jos diesel loppuu peli on ohi. Pelaajalla on tietty määrä rahaa. Rahalla hän voi ostaa asioita, kuten dieseliä pakettiautoon tai ongen. Kestävän kehityksen näkökulmassa peliin liittyy kohdat ei nälkää sekä puhdas vesi ja sanitaatio.

# Ohjeistus
# -Peli koostuu huoneista. Jokaisessa huoneessa voit:
# -Liikkua. Suunnat kerrotaan jokaisessa huoneessa.
# -Poimia. Jos huoneessa on esine, saat sen kirjoittamalla esineen nimen.
# Huomio! Joskus esineen poimiminen saattaa tarvita toisen esineen.
# -Katsoa oman tavaraluettelon sisällön sekä rahasi.
# -Ostaa, myydä tai antaa esineitä. Poimiminen toimii useimmissa huoneissa esineisiin, muttei kaikissa.
# -Ajaa pakettiautolla, jos se on huoneessa kanssasi. Dieseliä mahtuu maksimissaan 70 litraa tankkiin. Voit tankata tankin ostamalla dieseliä huoltoasemilla.
# -Tallentaa pelin ja sulkea ohjelman. Peliin voit palata pelin avautuessa ensimmäisestä päävalikosta.

# Pakettirakenne
# Luokat
# Sisältää auto, esine, huone ja pelaaja luokkien muuttujat sekä funktiot.

# alussa luodaan kaikki esineet ja huoneet. ne jaetaan listoihin, joihin voidaan verrata esim. esineiden nimiä ja koordinaatteja.
